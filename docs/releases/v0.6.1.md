# Harness v0.6.1

本版包含 [v0.6.0 的全部功能](v0.6.0.md)：首次默认空间选择、管理员账号和浏览器会话、显式多租户，以及知识管理、路由诊断和模板结构检查。

v0.6.0 首次发布时，GitHub 拒绝执行原 macOS ARM runner 配置：`macos-14-arm64-us-default is not supported`。本版将该构建迁移到 `macos-15`，重新验证五个平台的安装包。保留已推送的 v0.6.0 标签，不移动或覆盖该标签。

服务启动、存储格式和升级要求沿用 v0.6.0；既有单租户部署可直接保留原凭据、空间与数据卷。账号登录和多租户分别按需配置，不在升级时自动创建账号或迁移租户。

安装包包括 macOS ARM64 / x64、Linux ARM64 / x64、Windows x64 及 SHA256SUMS；服务镜像包含 Linux amd64 / arm64。实际发布状态以本版本 Release 和 Actions 结果为准。
