# Harness v0.6.2

本版交付 [v0.6.0 的全部功能](v0.6.0.md)：首次默认空间选择、管理员账号和浏览器会话、显式多租户，以及知识管理、路由诊断和模板结构检查。

正式打包同时包含发布环境和锁生命周期修正：

- macOS ARM 客户端使用 `macos-15` runner，替换本次 Actions 已拒绝执行的 `macos-14` 配置。
- 只读容器检查中的首次 `start` 和重启后 `list` 显式指定 `shared`，避免测试入口触发默认空间持久化。
- Store 和租户根锁在所有者销毁时显式解锁，避免并发子进程启动期间临时继承的文件描述符延迟释放。增加重复描述符回归，保留独占 writer 约束。

v0.6.0、v0.6.1 的标签保留；未完成的安装包或镜像不作为正式交付。最终五平台客户端与双架构镜像以本版本 Release 和 Actions 结果为准。

升级保留现有单租户配置、凭据、空间与原数据卷；账号和多租户分别按需配置，不自动创建或迁移。服务、客户端和备份工具均使用同版本产物。完整升级要求及边界见 [v0.6.0 说明](v0.6.0.md)。
