## 边界

测试使用临时store和临时凭据，不打包实际记忆、凭据、日志或备份。单租户面向同一租户的可信设备；显式多租户在同一进程内按独立凭据与Store隔离，每租户单writer，不提供水平扩容。跨空间共享与设备增量分两次保存，各自原子，可能部分成功。

业务QQ/Pi集成、灾难切换、OSS上传/恢复、各OS最低版本及实际任务净收益未因本仓库公开而增加验证。小型生产主机只安装已构建产物，不用于Rust/Docker编译；部署与升级另按部署和备份指南执行。
